# v5.34 — Calendar selection hotfix

- The coral-orange 1.5pt border now frames the full scheduled day in Home → Your Week. Activity icons remain clean, without their own orange border.
- Selecting a date in Scheduler now only selects that day and shows its agenda.
- The scheduling wizard opens only when you explicitly press **Schedule a workout**.

This protected OTA is for installations already on v5.32 or later. A legacy v5.31 Migration installation must complete the documented manual protected-release migration first.
