# My Personal Trainer 5.19

- Adds **Settings → Offline maps**.
- Download the verified Trinidad & Tobago street map directly in the app.
- Choose which installed country map is used for private endurance routes.
- Add a compatible Mapsforge country `.map` file from your phone; it is copied into private app storage and checked before it is used.
- Maps can be removed without deleting saved workout or route history.

Map data © OpenStreetMap contributors. Third-party country map packages may carry their own open-data license.
