# My Personal Trainer 5.18

- Adds a real, touchable Trinidad & Tobago offline street map for live and completed endurance routes.
- The optional 10 MB OpenStreetMap vector download is SHA-256 checked before it is stored privately on the phone.
- Live cycling, walking, and running routes now draw over local streets with no mobile data after the one-time download.
- Adds map storage controls and clear OpenStreetMap / ODbL attribution.
