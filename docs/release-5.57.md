## My Personal Trainer 5.57

- Fixes the end-of-workout handoff so the tailored five-minute cool-down is always accessible.
- If a completed session reaches its report without the cool-down first, use **Start 5-minute cool-down** to open the recovery timer and recommended stretch collage.
- The recovery action disappears once the cool-down has been completed, so it never loops back into the report.
