# My Personal Trainer v7.13

- Adds **Cast screen** to every live guided-workout stage.
- Opens Android's own television and wireless-display picker, then mirrors the exact workout shown on the phone.
- Requires no hosted Web Receiver, custom Cast application ID, or ongoing casting fee.
- Keeps the phone as the workout controller while the television displays the live session.
- Aligns Gym Lobby rank titles with the shared eight-rank ladder and keeps live endurance route status current as GPS points arrive.
