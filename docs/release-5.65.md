# v5.65 — Live workout surfaces

- Keeps an active guided workout visible through Android's lock-screen and notification Live Update surface.
- Shows elapsed workout time, exercise progress, current set, and Previous, Pause or Resume, and Complete Set controls outside the app.
- Adds a Coach Hero Wear OS companion that securely synchronizes the phone-owned workout state to a paired watch.
- Keeps exercise names and set counts synchronized when a set is completed from an external surface.

The phone remains the authoritative workout clock and record. Android and Samsung decide the exact promoted-notification or Now Bar placement supported by each device.
