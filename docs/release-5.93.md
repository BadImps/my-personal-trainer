# v5.93 — Calendar plans & incomplete days

- Marks passed, uncompleted workout and endurance plans with a light-red day tile and an **INCOMPLETE** ribbon.
- Uses a moon marker for rest days on Home, the training calendar, and Scheduler.
- Lets members select a future Home-calendar day and turn the primary card into **Create a Plan**.
- Lets Create a Plan start a workout plan, endurance plan, or both for the chosen day.
- Adds a four-second hold menu on current and future Scheduler/Home days: Edit Plan, Cancel Plan, Change Date, Change Plan, and Close.
- Moves strength plans and booked endurance appointments together when a date is changed.

This is a protected GitHub OTA for installations already using the production-signed
GitHub app channel.
