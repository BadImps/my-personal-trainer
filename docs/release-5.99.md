# v5.99 — Unified Plan navigation

- Replaces separate Workout and Endurance navigation entries with one Plan category.
- Plan starts with Workout, Endurance, or Combined.
- Workout and Endurance retain their established wizards and visual treatment.
- Combined plans guide the member through the existing Workout wizard first, then the
  existing Endurance wizard, and save a clear combined summary.

The Wear OS companion remains at v5.98 in this phone-focused release.
