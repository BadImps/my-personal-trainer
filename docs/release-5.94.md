# v5.94 — Calendar refinements

- Lets members take screenshots and screen recordings of their own app screens.
- Replaces compact calendar **Incomplete** labels with a clear X marker while retaining the full Incomplete ribbon in Your Week.
- Aligns rest-day moon markers with workout and endurance markers, with a neutral grey background.
- Preserves strength plans when moving them to another day in the same week.
- Uses a raised shadow instead of an orange outline for selected future dates.

This is a protected GitHub OTA for installations already using the production-signed
GitHub app channel.
