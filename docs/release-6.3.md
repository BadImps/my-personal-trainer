# My Personal Trainer v6.3

- Replaces separate Workout and Endurance navigation with one Plan flow: Daily, Weekly, or Custom, then Workout, Endurance, or Both.
- A combined plan keeps the familiar Workout and Endurance wizards and saves both into the shared calendar.
- Live walking, running, and cycling starts from a recent on-device GPS fix and keeps the live map camera on the latest position until you move the map yourself.
- Start and destination fields now include Google Maps pin controls. Search a place or tap the map to return an exact pin to that field.
- MapLibre remains available as the local/offline fallback.
