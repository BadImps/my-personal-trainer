# v5.33 — Canvas-locked Home and reminder polish

- Home’s **Next Workout** now opens the saved plan directly; edit and reschedule controls stay intentionally disabled for that shortcut.
- The Home week calendar now shows coral-outlined workout and endurance markers, stacking both when they share a date.
- Training-area and equipment selections keep their mint border around every rounded edge.
- Full-screen reminders use the selected Coach Hero image, with Start guided workout, Remind me later, and Not now actions. Remind me later offers 10, 20, 30, 45, and 60 minutes.

This protected OTA is for installations already on v5.32 or later. A legacy v5.31 Migration installation must complete the documented manual protected-release migration first.
