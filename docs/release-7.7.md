# My Personal Trainer v7.7

- Applies the approved full-month visual redesign to the actual Plan → My Calendar screen: larger month title, weekday divider, dark bordered calendar board, compact day tiles, and clear status legend.
- Workout and endurance day tiles show their activity label with the matching icon directly underneath.
- Selecting a future date no longer draws an orange frame; it is indicated with a deeper raised shadow. Today remains visibly framed.
