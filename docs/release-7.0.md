# My Personal Trainer v7.0

- Progress and Plan destination tiles now use top-aligned titles, bottom-aligned supporting notes, solid text shadows, thicker coral frames, and collision-safe spacing.
- Live tracking maps now use a closer navigation-oriented view: larger map panel, stronger route line, larger start and north markers, zoom controls, and preserved map rotation.
- Google Maps, MapLibre, and the private route-trace fallback now share the same start-dot and north-arrow visual language.
