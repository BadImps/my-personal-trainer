# My Calendar design lock v1

`approved-reference.svg` is the user-approved full-month source reference. It is
the versioned implementation contract for this screen state.

The Android implementation must retain the Coach Hero page chrome while reproducing the referenced calendar board's copy, hierarchy, colours, borders, tile states, icon placement, legend, and selected-day panel.

Validation target: MPT_API36, 1080 × 2400, 420 dpi, Android 16, default font/display scale, gesture navigation. A release capture belongs beside this reference before any production OTA.
