# Gym Lobby rank banners — approved component reference

## Approved direction

The user approved the eight individual rank banners in `user-approved-banner-styles.png`,
then requested that the exact material, colour, silhouette, lettering, and rank order remain
unchanged while their dimensions become smaller for a normal Gym Lobby member row.

`medium-compact-dimension-reference.png` records that approved compact direction:

- `34dp` high;
- `116dp` wide for short titles;
- `132dp` wide for `COMPETITOR` and `CONTENDER`;
- title text remains visible and carries the rank independently of colour.

## Scope

This lock applies only to the new Gym Lobby rank-banner component. It does not alter the
Coach Hero dashboard lock or the Mintfoil achievement-card lock.

## Validation profile

MPT_S23Ultra_API36 / Android 16 / default font scale / gesture navigation.
